《红楼梦》

（一）作者与成书背景

《红楼梦》原名《石头记》，又名《金玉缘》，作者曹雪芹（约1715—约1763），名霑，字梦阮，号雪芹。曹雪芹出身于清代江宁织造世家，曾祖曹玺、祖父曹寅、父辈曹頫三代四人相继担任江宁织造长达六十余年，家世显赫。雍正年间，曹家因政治牵连被抄家，从此败落。曹雪芹从“锦衣玉食”跌落到“举家食粥”的境地，这种巨大的人生落差，成为他创作《红楼梦》的直接动力。

曹雪芹“于悼红轩中披阅十载，增删五次”，倾尽毕生心血写成了这部不朽巨著。可惜全书尚未完稿，曹雪芹便因贫病而逝，仅留下前八十回。现存后四十回一般认为是高鹗所续。

鲁迅先生评价《红楼梦》：“自《红楼梦》出来以后，传统的思想和写法都打破了。”这部作品以贾、史、王、薛四大家族的兴衰为背景，以贾宝玉、林黛玉、薛宝钗的爱情婚姻悲剧为主线，描绘了一幅封建末世社会的全景图。

（二）故事情节

《红楼梦》的故事始于一个神话传说：女娲炼石补天，剩下一块未用的顽石，弃于大荒山青埂峰下。这块石头通了灵性，后随一僧一道下凡历练，幻化为贾宝玉出生时口中衔着的“通灵宝玉”。与之相应的另一个神话是：赤瑕宫的神瑛侍者每日以甘露灌溉一株绛珠仙草，仙草得以修炼成女体。为报答灌溉之恩，绛珠仙子追随神瑛侍者下世为人，发誓要用一生的眼泪来偿还——这便是林黛玉的前世与“还泪”之说。全书便以这块“无材补天”的顽石为视角展开叙述。

第一回至第五回为全书总纲。姑苏乡宦甄士隐梦见了通灵宝玉的故事，结识了寄居葫芦庙的穷书生贾雨村。元宵佳节，甄士隐的女儿英莲被人拐走，随后葫芦庙失火，甄家被烧成一片瓦砾。甄士隐历经家破人亡，最终随一僧一道出家而去。贾雨村则得到甄士隐的资助进京赴考，中了进士，步入仕途。此后，贾雨村因贪酷被革职，经人推荐到林如海家做家教，学生正是林黛玉。林黛玉母亲贾敏病逝后，贾雨村护送黛玉进京投奔外祖母——荣国府的贾母。小说通过冷子兴演说荣国府，向读者介绍了贾府的世系与现状。第五回“贾宝玉神游太虚境”是全书最关键的一回，贾宝玉在秦可卿房中梦游太虚幻境，看到了记载金陵十二钗命运的词曲判词，预示了书中主要女子的悲剧结局。

第六回至第十八回，随着林黛玉入贾府，薛宝钗也随母亲薛姨妈和哥哥薛蟠进京，住进了贾府。宝钗品格端庄、学识渊博，深得贾府上下喜爱。“金玉良缘”之说开始在贾府流传——宝钗有金锁，宝玉有通灵玉，被认为是一对佳偶。而黛玉与宝玉自幼同行同坐、同息同止，两人之间有着超越常人的心灵契合。这一阶段最为盛大的是第十六回至第十八回的“元妃省亲”——贾府的大小姐贾元春被晋封为贵妃，皇帝恩准她回家省亲。贾府为此耗费巨资修建了省亲别墅——大观园。元宵之夜，元春驾临，贾府上下盛装迎接，极尽荣华富贵。省亲过后，元春命众姐妹和宝玉搬入大观园居住，大观园从此成为全书最主要的活动舞台。

第十九回至第五十四回是大观园的鼎盛时期。宝玉和黛玉、宝钗以及众姐妹在大观园中结诗社、赏花饮酒、吟诗作对，度过了一段充满诗情画意的青春岁月。黛玉葬花、宝钗扑蝶、湘云醉卧等经典场景都发生在此期间。然而，表面的繁华之下暗流涌动——宝玉与黛玉之间的感情日益深厚，却始终不能公开；宝钗的端庄得体越发赢得贾府长辈的欢心。第三十三回“宝玉挨打”是全书的重大事件之一：忠顺王府上门索要戏子蒋玉菡，加之贾环进谗言说宝玉逼死了金钏儿，贾政勃然大怒，将宝玉打得半死。这一事件深刻暴露了贾府内部矛盾以及宝玉与封建家长之间的冲突。此后，袭人向王夫人进言，建议让宝玉搬出大观园，王夫人开始暗中筹划宝玉的婚事。

第五十五回至第八十回，贾府的衰败迹象日益明显。管理家务的王熙凤小产病倒，探春、李纨、宝钗三人共同理家，探春兴利除弊的改革虽有小成却难挽大局。抄检大观园是这一阶段最惊心动魄的事件——王夫人因绣春囊事件下令抄检大观园，晴雯、司棋、入画等丫鬟被驱逐，晴雯不久含冤而死。此后，迎春被迫嫁给虐待她的孙绍祖，香菱（即甄士隐之女英莲）被薛蟠的正妻夏金桂折磨致死，大观园中的青春与美好一点点被摧毁。第七十四回以后，贾府的颓势已无可挽回。

第八十一回至第一百二十回（后四十回）中，贾府走向彻底败落。元春病薨，贾府失去了最大的政治靠山。此后贾母去世、王熙凤病故、贾政被革职查办，荣宁二府被抄家，贾赦、贾珍被流放。宝玉的婚姻问题终于有了结果——在贾母和王夫人的安排下，宝玉与宝钗成婚。而此时的黛玉已病入膏肓，在宝玉和宝钗成婚的当晚，黛玉焚稿断痴情，含恨离世。宝玉在经历了家道中落、爱情破灭之后，终于看破红尘，随一僧一道出走，回归青埂峰下，完成了“石头”的历练之旅。全书以“落了片白茫茫大地真干净”作结。

（三）主要人物

贾宝玉是全书第一主人公。他衔玉而生，被视为贾府的命根子。他厌恶仕途经济，痛恨八股文章，认为“女儿是水做的骨肉，男子是泥做的骨肉”，对身边的女子怀着真诚的尊重与怜惜。他追求真情真性，是封建礼教的叛逆者，但也是无力反抗的悲剧人物。

林黛玉是绛珠仙草下凡，以眼泪偿还宝玉前世灌溉之恩。她才情卓绝、心性高洁，却又多愁善感、尖酸刻薄。她与宝玉心灵相通，是宝玉唯一的精神知己。然而她孤苦无依、体弱多病，最终在爱情破灭中香消玉殒。

薛宝钗是封建淑女的典范——端庄大方、知书达理、人情练达。她爱宝玉却从不表露，处处以封建妇德规范自己。她最终成为宝玉的妻子，却只得到一段没有爱情的婚姻。

王熙凤是贾府实际管家人，精明强干、泼辣狠毒，协理宁国府、弄权铁槛寺，充分展现了她的才干与贪婪。她是贾府由盛转衰的见证者和推动者。

此外，贾母、贾政、王夫人、元春、探春、惜春、妙玉、史湘云、袭人、晴雯等众多人物，个个形象鲜明，共同构成了这部“中国封建社会后期社会生活的百科全书”。

（四）主题思想与艺术特色

《红楼梦》的主题是多层次的。最表层是宝黛钗的爱情婚姻悲剧；中层是贾府由盛而衰的家族悲剧；深层则是整个封建末世必然走向灭亡的历史悲剧。“大旨谈情”是作者在第一回便明确点出的创作主旨——此“情”不仅是男女情爱，更包含对一切美好生命与真挚情感的珍视与追怀。

《红楼梦》的艺术成就达到了中国古典小说的巅峰。在结构上，它以日常家庭生活为叙事中心，“慵慵散散、不紧不慢”地展开。全书“大事件”不多，却在琐碎的日常中暗藏巨大的悲剧力量。在人物塑造上，曹雪芹“只作记录、描情态而不断是非、判忠奸”，每一位人物都立体生动、耐人寻味。小说中的两百多首诗词曲赋，既服务于情节发展和人物塑造，又具有独立的艺术价值。作品还融合了诗词、绘画、医药、礼俗、园林、饮食等中国传统文化精华，被誉为“封建末世的百科全书”
