《三国演义》

（一）作者与成书背景

《三国演义》全称《三国志通俗演义》，作者罗贯中（约1330—约1400），名本，字贯中，号湖海散人，元末明初小说家。《三国演义》是中国文学史上第一部长篇章回体历史演义小说。

这部作品的成书经历了一个漫长的积累过程。三国故事在民间流传已久，宋元时期已成为说话艺人热衷的题材，元杂剧中也有大量三国戏。罗贯中在这些民间创作的基础上，依据陈寿《三国志》及裴松之注等正史材料，结合自己的生活经验和历史见解，进行了系统的艺术加工，最终写成了这部不朽巨著。《三国演义》共一百二十回，描写了从东汉灵帝中平元年（184年）黄巾起义到西晋武帝太康元年（280年）全国统一前后近一个世纪的历史风云。全书涉及人物逾一千一百位。

（二）故事情节

《三国演义》大致可分为五个阶段。

第一阶段：黄巾之乱与群雄初起（第一回至第九回）

东汉末年，朝政腐败，十常侍专权，民不聊生。巨鹿人张角兄弟发动黄巾起义，天下大乱。在镇压黄巾军的过程中，刘备、关羽、张飞三人桃园结义，踏上了保国安邦的道路。与此同时，各路豪强纷纷起兵，曹操、孙坚等英雄相继登场。董卓率兵入京，废少帝立献帝，独揽大权，残暴不仁。曹操自告奋勇刺杀董卓未成，逃出洛阳后发矫诏召集十八路诸侯讨伐董卓。关羽在汜水关前“温酒斩华雄”，威震诸侯。虎牢关前，刘关张三英战吕布，更是传为佳话。但诸侯各怀异心，联军不久瓦解。董卓挟持汉献帝迁都长安，最终被王允用连环计（貂蝉离间董卓与吕布）所杀。

第二阶段：群雄逐鹿与曹操统一北方（第十回至第三十三回）

董卓死后，天下更加混乱。曹操在镇压黄巾军和讨伐董卓的过程中不断壮大实力，采纳谋士“挟天子以令诸侯”的策略，将汉献帝迎至许昌。此后曹操先后消灭吕布、袁术、张绣等势力，并在官渡之战中以少胜多，大败袁绍。官渡之战是三国时期三大战役之一，曹操通过此战统一了北方，成为当时最强大的军阀。

刘备此时尚未得志，先后投靠曹操、袁绍、刘表等人。在荆州期间，刘备三顾茅庐，请出了隐居南阳的诸葛亮。诸葛亮为刘备分析了天下大势，提出了“先取荆州为家，再取益州成鼎足之势，然后图取中原”的《隆中对》战略。

第三阶段：赤壁之战与三国鼎立（第三十四回至第五十回）

曹操统一北方后，率大军南下，意图一举消灭孙权和刘备，统一全国。刘备此时兵微将寡，派诸葛亮过江联合孙权。诸葛亮舌战群儒、智激周瑜，促成了孙刘联盟。赤壁之战中，周瑜用火攻大破曹军——黄盖献苦肉计、庞统献连环计、诸葛亮借东风，火烧曹操战船。曹操大败，狼狈北逃，三国鼎立的局面由此形成。

第四阶段：三国争霸（第五十一回至第一百零四回）

赤壁之战后，刘备借荆州、取益州、夺汉中，建立了蜀汉政权。关羽镇守荆州，水淹七军、威震华夏，但随后被孙权偷袭，败走麦城，被擒杀。关羽的死引发了刘备对东吴的报复性征伐。刘备不顾诸葛亮等人的劝阻，亲率大军伐吴，在夷陵之战中被陆逊用火攻打得大败，退至白帝城，不久病逝。

刘备死后，诸葛亮辅佐后主刘禅，继续推行联吴抗魏的方针。他七擒孟获，平定了南方蛮族的叛乱。此后诸葛亮六出祁山，北伐曹魏。其间上演了空城计、挥泪斩马谡等经典故事。诸葛亮“鞠躬尽瘁，死而后已”，最终因积劳成疾，病逝于五丈原军中。

第五阶段：三国归晋（第一百零五回至第一百二十回）

诸葛亮死后，姜维继承其遗志继续北伐，但已无力回天。曹魏政权逐渐被司马氏家族控制。司马懿发动高平陵之变，诛杀曹爽，掌握了魏国大权。此后司马师、司马昭相继专权，司马昭派钟会、邓艾伐蜀，蜀汉灭亡。司马炎篡魏建立西晋后，派兵伐吴，吴主孙皓投降。至此，三国归于一统，天下重新统一于西晋。全书以“天下大势，分久必合，合久必分”作结。

（三）主要人物

诸葛亮是作者心目中的“贤相”化身——忠贞不渝、智谋超群，具有“鞠躬尽瘁，死而后已”的高风亮节。他神机妙算、呼风唤雨，是智慧与忠诚的象征。草船借箭、借东风、空城计、七擒孟获、六出祁山，处处闪耀着他的智慧光芒。

曹操是一位极其复杂的人物——既是雄才大略的政治家、军事家，又是奸诈多疑的“奸雄”。他“挟天子以令诸侯”，用人唯才，但同时也心狠手辣，“宁教我负天下人，休教天下人负我”的名言充分体现了他极端利己的性格。

关羽是“义”的化身——忠义无双、武艺超群，被后世尊为“武圣”。千里走单骑、过五关斩六将、华容道义释曹操，处处体现他的忠义与气节。但他也刚愎自用，最终兵败身亡。

张飞勇猛刚烈、粗中有细，长坂坡一声喝退曹军的故事家喻户晓。刘备以仁德著称，三顾茅庐的诚意和携民渡江的仁心，体现了他“以人为本”的政治理念。此外，周瑜、司马懿、赵云、黄忠、吕布、貂蝉等人物也都栩栩如生，各具风采。

（四）主题思想与艺术特色

《三国演义》的主题思想十分丰富。作品通过对汉末三国历史的艺术再现，总结了各个政治集团成败兴衰的历史经验，突出强调了争取人心、延揽人才、重视谋略三大要素的重要性。在政权立场上，小说贯穿了鲜明的“拥刘反曹”倾向，将蜀汉视为矛盾的主导方面，隐含着人民对汉室复兴的希望和对皇室正统的认同。同时，作品也反映了动乱年代百姓的疾苦，表达了人民反对战乱分裂、渴望和平统一的愿望。

在艺术上，《三国演义》取得了多方面的成就。首先，它成功塑造了众多鲜明的人物形象。全书写了四百多人，主要人物性格鲜明、形象生动——诸葛亮的神机妙算、曹操的奸诈多疑、关羽的忠义、张飞的勇猛，都成为某一类型人物的代表。其次，小说在战争描写上虚实结合、详略得当。再次，作品将人物置于激烈的矛盾冲突中，通过惊心动魄的军事政治斗争来展现人物性格。《三国演义》为古典小说的人物画廊贡献了众多经典形象，标志着中国古典小说人物塑造的新发展。正因如此，“三国文化”对中国人的精神生活产生了广泛而深远的影响。
