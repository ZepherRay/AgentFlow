准备1：配置切割 Settings、chunk_size、chunk_overlap

准备2：配置向量化模型 Settings、embed_model、DashScopeEmbedding( model_name, api_key )



1.加载文档 

- documents = SimpleDirectoryReader(input_files=['path']).load_data()

2.配置向量数据库

- chromadb.PersistentClient 
- chroma_client.get_or_create_collection 
- ChromaVectorStore() 
- StorageContext.from_defaults()

3.构建向量知识库索引、并存储 （分块、向量化、完整存储 建立索引）

- index = VectorStoreIndex.from_documents(documents, storage_context)

4.打印记录 

- chroma_collection.count()







核心2：rag检索增强生成/查询



准备1：设置向量嵌入模型 Settings.embed_model = DashScopeEmbedding( model_name, api_key )

准备2：设置回答模型 Settings.llm = DashScope( model_name, api_key )



1、连接已有向量库

- chromadb.PersistentClient() 
- chroma_client.get_or_create_collection() 
- ChromaVectorStore()

2、载入已有索引

- index = VectorStoreIndex.from_vector_store(vector_store=vector_store)

查记录 chroma_collection.count()

无记忆查内容 index.as_query_engine(similarity_top_k=3).query(内容)

有记忆查内容 index.as_chat_engine(similarity_top_k=3, memory, system_prompt ).chat(question)





语法细节

Document → 内部自动分块 Settings → 向量化 → 写入向量库 index = VectorStoreIndex.from_documents(documents, storage_context) 你已经分好块 → 跳过内部分块 → 向量化 → 写入向量库 index = VectorStoreIndex(nodes) 仅加载已有索引来检索 index = VectorStoreIndex.from_vector_store(vector_store)

query → 向量化 -> 检索文档块 → 拼 prompt → LLM 生成 query_engine = index.as_query_engine/as_chat_engine(similarity_top_k=3) query_engine.query(内容)

query → 向量化 → 检索文档块 → 返回文档块 （仅仅拿私有知识库内容） retriever = index.as_retriever(similarity_top_k=3) results = retriever.retrieve(内容)
